# General research or literature synthesis

1. Map the question into subclaims and list the source type most capable of answering
   each one. Search primary and official sources early, not only commentary about them.
2. Run a query fan: the user's wording; plausible synonyms; a domain-specific term;
   a skeptical or contrary framing; and a source-targeted query such as `site:` or
   `filetype:pdf`.
3. If the vocabulary is uncertain, read an overview, review paper, textbook chapter, or
   reference work only to acquire the field's jargon, canonical authors, and landmark
   sources. Re-search using that vocabulary.
4. Build a seed set of strong sources. Follow their references backward to foundations
   and citations forward to replications, corrections, criticism, and newer versions.
5. Search disagreements deliberately. Vary framing and terminology so the result set is
   not merely several pages repeating one source.
6. Create an evidence table in scratch space: subclaim, strongest source, independent
   corroboration, date/version, counterevidence, and confidence. Write from this table.

Prefer current primary documentation for present-day facts and the contemporaneous
record for historical claims. Search in relevant languages when names, institutions, or
events are not primarily English-language; translate query variants rather than relying
only on translated summaries.
